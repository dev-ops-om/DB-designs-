# 🗄️ Database Design Series

A collection of real-world database designs, entity-relationship (ER) models, and schema explanations.

Each folder contains an in-depth breakdown of a specific system design, complete with visual ER diagrams and key architectural decisions.

---

## 📂 System Designs

1. [**Comic-Con Parking System**](./Comic-Con%20Parking%20System%20-%20Database%20Design/README.md) — Multi-tier convention parking system handling physical vehicle fit, credential-based access clearance, and session ticketing.
2. [**Fitness Influencer Coaching Platform**](./Fitness%20Influencer%20Coaching%20Platform/README.md) — Remote personal training platform managing coaching plans, subscriptions, client check-ins, biometric metric logs, 1-on-1 sessions, and payments.
3. [**Instagram Thrift & Creator Store**](./Instagram-thrift-creator-store/README.md) — E-commerce data model featuring class-table inheritance for 1-of-1 vintage items vs made-to-order creator drops, order tracking, and shipments.
